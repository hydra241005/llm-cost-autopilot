# A/B Evaluation Architecture

## Purpose

A/B evaluation allows routing traffic to be split across experimental configurations. The platform can route a configured percentage of traffic to a challenger policy or classifier while preserving the baseline experience for the remainder.

## Supported split examples

- 100/0
- 95/5
- 90/10
- 50/50

## Recorded outcomes

- request count
- latency
- routing accuracy
- disagreement rate
- quality score
- estimated cost
- cost savings
